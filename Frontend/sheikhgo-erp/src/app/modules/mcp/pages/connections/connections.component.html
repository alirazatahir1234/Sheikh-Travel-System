Checklist

  1. Clone / pull SheikhGo-MCP and run npm install.
  2. Set SHEIKHGO_REPOSITORY to your Sheikh-Travel-System root.
  3. Add the sample config (or use config/cursor.mcp.json / config/claude-code.mcp.json).
  4. Reload MCP servers in Cursor, or restart Claude.
  5. Use Chat in this console to copy prompts with the right tool-group context.
